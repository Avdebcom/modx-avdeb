# Changelog

## 1.0.0 - 2026-11-22

- First release: `AvdebProducts`, `AvdebProduct` and `AvdebButton` snippets, `{avdeb-products …}` tags in any content (plugin), and system settings for the referral code, secret key and display defaults.
- Grid, carousel, list and spotlight layouts; horizontal, hero and card single products; referral buttons; `&tpl` chunks for your own markup.
- Products are cached in the MODX cache (partition `avdeb`). If AVDEB can't be reached, the last good copy is shown for a week. Clearing the site cache refreshes them.
